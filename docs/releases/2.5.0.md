## 反映条件

端末情報は利用者が更新版を起動し、必要なFirestoreルールが公開されてから送信されます。管理者だけが更新しても、旧版を使い続けている問い合わせ者の端末情報は取得できません。過去の端末情報を遡って復元する機能ではありません。

この更新にはローカルの未反映変更（お問い合わせ、広告分析、時間割拡張、Cwitter、3Dマップなど）も含まれます。Firebaseの反映事項は各機能のドキュメントを参照してください。

## 配信用AAB

配信に使うには既存のPlayアップロードキーの署名が必要です。`android/key.properties` と対応するキーストアはGitに含めません。署名情報を用意した環境で `flutter build appbundle --release` を実行してください。署名なしの検査用ビルドは、そのままPlayへアップロードできません。
