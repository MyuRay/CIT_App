# CIT App 2.3.3

バージョン: `2.3.3+84`

## 変更内容

- 起動時に公開済みバージョンを確認し、古い場合に更新案内を表示。
- 「更新する」で Android は Google Play、iOS は App Store を開く。「あとで」で閉じて利用を続けられる。
- 通信失敗や確認タイムアウト時も通常起動する。既存のダイアログやバックグラウンド中は表示を待つ。
- マイページのバージョン表記を `2.3.3` に統一。

## 公開時の注意

- Android と iOS はそれぞれのストアで公開済みのバージョンを別々に管理する。
- 審査中・段階配信中に Firebase の公開バージョンを進めない。対象ユーザー全員が更新できることを確認してから設定する。
- この案内機能を持たない既存のアプリには後から表示を追加できない。機能を含む版をインストールした後の更新から案内できる。
- iOS は Mac で依存関係を更新し、ビルド・実機確認してから配信する。

設定と検証の手順: [起動時のアップデート案内](../APP_UPDATE_PROMPT.md)
