# 大学のExcel時間割の取り込み

更新日: 2026-09-18

## 操作

1. 時間割タブの編集モードで「Excelから自動入力」を開く。
2. 大学の学生時間割表の `.xlsx` を選択し、検出された学期と取り込み先の時間割を選ぶ。
3. 選んだ学期の講義名・曜日・開始時限・連続コマ数・教員・教室を確認し、必要なら編集する。
4. 「この内容で適用」で保存する。既存の時間割をクリアする操作は初期状態では無効。

曜日・時限を持たない集中講義は自動配置しない。確認画面に科目名と手動追加の案内を表示する。

## 対応形式

- 後期のコンパクトな出力（曜日見出しが D/J/P/V/AB/AH 列、時限が C 列）。
- 従来の横に広い出力（曜日が O/AJ/BE/BZ/CU/DP 列、時限が I 列）。
- 曜日見出しから列を検出するため、シート名や列位置の変更にも対応する。旧形式は見出しが読めない場合の互換処理を残している。
- 時限ごとに行数が変わる表、全角の時限番号、2ページ目の10限に対応する。
- 連続した同名・同教員・同教室の講義は複数コマの1講義にまとめる。離れた時限はまとめない。
- 時限番号より前の行に次の講義名が始まる場合は、前の講義の単位数欄を境界としてタイトルの先頭を復元する。番号と同じ行が空でも、その下の講義情報を読む。教員・教室の一致だけで異なる講義を結合しない。
- 時間帯の説明や集中講義の欄を通常の時間割として読まない。
- 片方の期のみの2シート、前期・後期両方の4シートを学期別に解析する。各シートの年度・学期見出しを使い、シート番号や順序から前期・後期を決めつけない。
- 前期／春学期、後期／秋学期の表記を扱い、年度が異なる時間割も分ける。連続講義の結合や警告表示は選択した学期内で行う。
- 見出しがない場合は時限の続きが一意に分かるページのみ連結し、時限が最初に戻ったら別の候補にする。学期不明であることを明示して内容確認を促す。

1学期だけなら検出した学期を選択済みにする。複数学期の場合は利用者が選ぶまで先に進めない。取り込み先は既存の時間割から選べる。年度・学期が一致する保存先が1つだけなら候補として選択するが、利用者が変更できる。保存前の確認画面にもExcelの学期と取り込み先を表示し、既存の時間割名は変更しない。キャンセル時は保存しない。

解析APIは `parseWorkbookBytes` で学期ごとの `SemesterScheduleImport` を返す。旧 `parseExcelBytes` は1学期ファイルの互換用で、複数学期を一括適用しないよう例外にする。

## 任意の抽出改善データ

データ提供は初期状態で有効。確認画面でチェックを外すと提供せずに取り込める。チェックが入った状態で「この内容で適用」を押して取り込みが完了した場合だけ、選んだ学期の抽出結果・修正内容と、その学期の時間割セルのみから再構成したExcelを既存の提供先に送信する。キャンセル時や、選ばなかった学期のシートは送信しない。

元の氏名・学籍番号欄、元のファイル名・シート名、時間割以外のシート、元の文書プロパティはコピーしない。列が変わると漏れる固定セルのマスク処理は廃止した。提供データはログイン中のユーザーIDに関連付くため、完全匿名とは表記しない。安全な提供用ファイルを作れない場合は提供を中止し、元ファイルにはフォールバックしない。

## 検証

`test/services/schedule/excel_schedule_import_test.dart` に匿名の再現データを用いた回帰テストを収録。提供された後期Excelでも実際の抽出を検証した。元のファイルは変更・リポジトリ収録・外部送信していない。

2026-09-18: 利用者の画像にある「人間工学概論 経デ2年」「システム方法論 経デ2年」が次の時限の「2年」「デ2年」に分断される症状を、講義の先頭と時限番号が1行ずれる再現データで確認・修正した。今回の画像の元Excelは未入手のため、そのファイルでの原因確定・実機再検証は未実施。

- 回帰テスト6件を追加。分断の復元、同教員・同教室の別講義の分離、空行後のタイトル、折り返された注記の誤検出防止、提供用Excelでの再現性と個人情報除外、保存後の同一講義ID・連続コマ数・開始セルを検証。
- 講義項目の抽出、学期選択、取り込み確認画面を含む関連テスト101件成功。元ファイルの指定を要する任意テスト1件はスキップ。
- 既存の検証用Excel424件を読み込み、706学期・7,989講義・17,684コマ、失敗0。件数は修正前と一致。全件の抽出内容に正解を付けた精度検証ではない。

保存済みの時間割を自動修復する変更は含まない。修正版でExcelを再取り込みし、内容確認後に適用する。ログは `build/excel-training/split-*.log`（Git対象外）。

学期選択画面は `test/widgets/excel_import_semester_dialog_test.dart` で単独学期の識別、複数学期の明示的選択、保存先の変更、キャンセル、ライト/ダークと小画面を検証する。4シートの検証データは匿名の再現データで、実ファイル検証には利用者提供の2シート後期ファイルを使用した。
