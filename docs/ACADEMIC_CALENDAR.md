# 学年暦

ホームの学年暦は `lib/widgets/home/academic_calendar_card.dart`、月のグリッドは `lib/widgets/home/academic_month_calendar.dart`。年間画像の取得・表示は `lib/screens/home/home_screen.dart`。

## 操作

- 初期表示は当月。年度は4月から翌年3月までを現在日付から求める。
- 左右ボタンまたはスワイプで月を移動。年度境界は左右ボタンで移動できる。
- 「当月に戻る」は当月へ戻り、日付の選択を解除する。
- 見出しはカレンダーアイコンと、学バス情報などと同じ `titleMedium` の文字スタイルを使う。
- 月の予定を日付順に全件表示する。通常は日付と1行のタイトルを横並びにし、上下余白を4pxにする。長いタイトルは省略する。
- 日付を押すとその日の予定行を背景・枠・太字で強調し、高さを内容に合わせて広げる。タイトル全文と補足の先頭3行を表示し、上下余白は8px。長い補足の全文は予定行を押して確認できる。
- 他の日の予定もコンパクトに表示したまま、同じ日付を再度押すか選択日を変えると元の高さに戻る。
- 予定行を押すとタイトルと補足を省略せずに表示。長文はスクロールできる。
- カード右上の「年間画像」は登録済みの全画像を表示。画像を押すと拡大でき、複数ページは左右に切り替えられる。

## データと保守

- Firestore の `academic_calendar_events`、管理画面の予定登録形式は従来どおり。
- 読み込む範囲は表示年度の4月1日から翌年3月31日。日付選択・同年度の月移動・ホームの再描画で購読を作り直さない。
- 読み込み中・取得失敗・予定なしを区別する。取得失敗では「再読み込み」を表示する。
- 年間画像の Storage パス `year_calender` は既存データとの互換性のため維持。画像は年度ごとに自動分類されないため、管理側で公開対象を管理する。
- 週の開始曜日設定を反映。ホームでは表示月の週数・文字サイズに合わせて高さを変え、5週の月に空の6週目を確保しない。隣の月は自身の高さでレイアウトし、スワイプ時のbottom overflowを防ぐ。
- 選択日はテーマの背景色・文字色の組を使用し、今日の枠・日付の読み上げ・予定件数も維持する。詳細はシステムナビゲーション領域を避けて表示する。

## 確認

`test/widgets/home/academic_calendar_card_test.dart` と `test/widgets/home/academic_month_calendar_test.dart` の26件を実施。見出しスタイル、全予定の維持、同日の複数予定の強調・展開と解除、年間画像の右端配置、月・年度移動、当月への復帰、補足全文、取得失敗からの再試行、購読の維持を確認する。

幅320/390/600、文字サイズ100/200%、日曜/月曜始まり、ライト/ダーク、下部48pxのシステム領域、6週月を含む画面テストで確認。プレビュー用の予定はテスト内だけにあり、本番の予定データは変更しない。実機での最終操作確認は別途必要。
