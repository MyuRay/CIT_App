# アカウントと公開プロフィールの分離

2026-11-16、ローカル実装。未デプロイ・既存データ未移行。

`users/{uid}` は本人・管理者に読み取りを限定し、一般利用者は `public_profiles/{uid}` を読む。公開文書はサーバーだけが書く。表示名、プロフィール画像、Cwitter ID・自己紹介・タグ・SNSリンク・固定投稿・有効状態のみを許可リストでコピーし、メール、学籍番号、同意記録、その他の未知のフィールドをコピーしない。本人の表示名・自己紹介等に自ら記載した情報は公開内容に含まれる。

`syncPublicProfile` はイベントに入った古い内容をコピーせず、トランザクションで現在のアカウントと退会ジョブを読み直す。アカウント不存在・退会中は公開文書を削除する。退会ワーカーにも公開文書の削除を追加した。

プロフィール取得、画像・表示名の監視、Cwitterのユーザー検索・フォロー一覧、フォロー通知からの遷移、他人の固定投稿監視を新しい保存先へ切り替えた。本人のプロフィール編集は従来の非公開アカウントへ保存する。ユーザー通報は相手のメールを取得できなくても送信できるようにした。

## 反映する順序

1. 現在有効な本番ルールを取得し、他作業の未反映差分を混ぜずに変更を準備・検証する。
2. `public_profiles` のクライアント書き込み拒否、同期関数、削除ワーカーを反映する。既存アカウントのバックフィルを実施する。
3. 新アプリの配信・最低対応バージョンの案内を行い、プロフィール・検索・通報・通知・固定投稿を確認する。同期は非同期なので他人の画面への反映に短い遅延が生じる。
4. `users` の読み取り制限を反映する。旧アプリからの他人のプロフィール取得は拒否されるため、移行前に制限だけを反映しない。

バックフィルは次のコマンド。`--apply` がない場合、公開用フィールドの対象件数のみ数え、書き込みを行わない。アカウント内容・メール・UIDをログに出さない。適用時もトランザクションで現時点の値と退会状態を確認する。今回は未実行。

```powershell
node scripts/backfill_public_profiles.cjs --project=cit-app-2de1c
node scripts/backfill_public_profiles.cjs --project=cit-app-2de1c --apply
```

**この変更だけでは投稿側の `authorEmail`、ちばちゃんねるの `authorId`・画像パス・通知からの対応関係は解消しない。** これらの保護と既存データ移行が済む前に、ポリシーをすべて実施済みとして公開しない。

本番ルールの取得は `node scripts/inspect_legal_live.cjs`。一覧APIに障害がある場合は `--direct` で現在の既定リリースだけを取得できる。今回の環境では両方がHTTP 500で失敗し、書き込み・デプロイは行っていない。本番Firestoreの設定取得は成功し、保存先が `nam5`（米国複数リージョン）であることを確認した。利用者の文書は取得していない。
