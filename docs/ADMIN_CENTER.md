# 管理センター

確認日: 2026-09-16

## 入口と使い方

マイページ → 管理センター。これまでマイページに並んでいた管理機能を、専用画面にまとめた。

- 対応待ち: 投稿申請・未対応の問い合わせ・未対応の通報を確認し、対象画面へ移動する。問い合わせのカードからは未対応で絞り込んだ一覧を開く。
- よく使う機能: 各機能の星で追加・解除する。端末内にログインユーザーごとに保存する。
- 検索: 機能名のほか「スポンサー」「時刻表」「権限」などから探せる。
- 分類: 配信・スポンサー、問い合わせ・安全管理、キャンパス運営。
- 件数: 管理センターを開いた時、画面へ戻った時、アプリ復帰時、手動更新時に取得する。常時リアルタイムの件数ではない。取得失敗を0件として表示しない。

既存の通知、掲示板、通報、問い合わせ、ユーザー、広告、講義期間、学年暦、学バスへの導線を維持し、投稿申請への直接導線も追加した。掲示板の金色スポンサー設定は従来の掲載設定から操作する。

## 一覧の改善

### お問い合わせ

件名・本文・送信者・IDで検索する。状態とカテゴリを組み合わせ、未対応優先／古い順／新しい順で並べ替える。統計は「受付状況の詳細」で展開する。返信や状態変更は既存の詳細画面を使用する。

### ユーザー

名前・メール・UIDの検索、有効／停止中／管理者の絞り込み、登録日・最終ログイン・名前の並べ替えに対応する。カードのメニューからUIDとメールをコピーできる。アカウントや権限の変更は既存の詳細画面で行う。

ユーザー検索のたびにFirestoreの購読を作り直さない。管理者表示もユーザーごとの個別取得から、権限一覧の共有ストリームに変更した。統計は取得した一覧から集計する。現在の仕様は全件取得であり、大規模化した場合のサーバー検索・ページ分割は別途検討する。

### 通報

状態、対象種類、内容・対象者・通報者・IDの検索を組み合わせる。初期表示は未対応・古い順。対象の内容と対応メモを確認・更新できる。保存エラー時は成功表示せず、詳細を閉じずに再試行できる。

### 通知

通知履歴へタブを切り替えても、作成中の入力内容を維持する。プレビューは入力に追従し、選択した種類・タイトル・本文を保存する。種類変更時に手入力したタイトルを上書きしない。送信の二重実行を防ぐ。画面を閉じた後やアプリ再起動後の下書き保存は含まない。

## 実装と権限

- 機能の定義: lib/models/admin/admin_destination.dart
- 管理センター: lib/screens/admin/admin_dashboard_screen.dart
- 各画面への遷移: lib/screens/admin/admin_destination_page.dart
- 対応待ち件数・お気に入り・管理者一覧: lib/core/providers/admin_dashboard_provider.dart
- 共通のアクセス確認: lib/widgets/admin/admin_access_gate.dart
- 検索・状態ラベル・スクロール領域: lib/widgets/admin/admin_list_components.dart

権限が確認できてから管理用のデータ取得を開始する。currentUserAdminProvider は認証状態とユーザーごとの権限の変更を追従する。以前のasyncExpandによる無期限ストリーム待ちを解消し、ログアウト・別アカウントへの切り替え・権限取消を反映する。

この変更ではFirestoreルールやデータ形式を変更していない。本番の通知送信・問い合わせ返信・ユーザー変更は行っていない。
