# 見て試せる使い方ガイド

更新日: 2026-09-16

初回のタブ案内を、5項目の操作見本に置き換えた。マイページの「チュートリアルを確認」から再表示できる。

| 項目 | 試せること |
| --- | --- |
| ホーム | メニューからカード編集を開く、表示切り替え、長押しで並べ替え |
| 時間割 | 鉛筆で編集モードへ切り替え、Excel取り込み後の表示、出欠集計の確認 |
| 交流 | Cwitterとちばちゃんねるの切り替え |
| 掲示板 | ＋から申請・承認までの流れ、ⓘの役割を確認 |
| マイページ | キャンパスを選択し、「使い始める」でメインキャンパスに保存 |

上部の5つのアイコンから任意の項目へ移動できる。「戻る」でも操作見本の状態は保持する。「次へ」で順に進み、「使い始める」でホームへ移動する。各項目の「○○を開く」は実際のタブを開く。「あとで」とシステムの戻る操作は、開いていたタブを変えずに閉じる。

## 実装と表示条件

- ガイド: lib/screens/main/widgets/visual_tab_tutorial.dart
- 操作見本: lib/screens/main/widgets/tab_tutorial_demo.dart
- 起動・終了処理: lib/screens/main/main_screen.dart
- 再表示の入口: lib/screens/profile/simple_profile_screen.dart

投稿・時間割・ホームカードの見本はローカルなWidgetの状態だけで動作する。キャンパス選択は現在の設定を初期表示し、選択後に「使い始める」を押すと setPreferredBusCampusProvider 経由で保存する。保存が完了してからホームへ進み、天気と学バスの初期表示も選んだキャンパスに合わせる。

キャンパスを選択し直さなかった場合は既存設定を維持する。「あとで」、システムの戻る、「○○を開く」では未確定の選択を保存しない。保存中は操作を止め、失敗時は選択を残して再試行できる。ガイドを進めるだけでは実際のタブを切り替えないため、タブ閲覧や広告表示の計測を発生させない。

利用規約同意後に開始し、メール移行の案内中はその終了を待つ。既存の tab_tutorial_seen_version とバージョン2.0.0の完了判定を維持し、既に案内を見たユーザーには自動で再表示しない。再確認はマイページから行う。

本文は縦スクロールでき、「戻る」「次へ」は下部に固定。システムの安全領域を確保する。固定時間で進む演出や点滅はなく、自分のペースで操作できる。
